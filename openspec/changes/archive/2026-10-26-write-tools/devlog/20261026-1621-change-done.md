**What the change delivers** (13 commits on `change/write-tools`, `git diff 49514d9..HEAD`: 49 files, +2542 −238):
- **`command`:** INSERT, UPDATE, DELETE and MERGE, with OUTPUT. UPDATE and DELETE need a WHERE clause.
- **`ddl`:** tables, columns, constraints, indexes, views, schemas and sequences, and TRUNCATE.
- **`execute`:** EXEC of a user procedure with literal parameters.
- **Groups:** each tool is its own group, denied by default. A tool is offered only where its group is allowed,
  and annotated destructive and not idempotent.
- **All or nothing:** each write batch runs in one transaction with `XACT_ABORT` on. A batch is rolled back on
  any error or timeout, or when it goes over `maxAffectedRows` (default 1000, layered and approved like the
  other limits).
- **The names rule:** a write may only name objects in the target database.
- **Responses and audit:** a write returns `committed` and `rows_affected`, plus paging when there are result
  sets. The audit has `rows_affected` on `executed`, and `cap` and `affected` on a `failed` event from the cap.
- **Wrong-tool refusals** say whether the right tool is allowed on the database or denied there.
