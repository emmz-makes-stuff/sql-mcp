Emmz's answers (2026-10-27/28):
- **Script directory mirrors the audit log:** `<project>/.sql-mcp/scripts/` only when `.sql-mcp/` exists and the
  file can be created there, otherwise `~/.local/state/sql-mcp/scripts` (`%LOCALAPPDATA%\sql-mcp\scripts`).
- **Temp file reserved per suffix:** the first suffix whose `.sql` and `.sql.tmp` are both free; the `.sql.tmp` is
  created with `CreateNew` and moved with `overwrite: false` (on a race, the next free name).
- **`init` says what it added:** "Created <path>." for a new `.gitignore`, "Added scripts/ to <path>." for an
  existing one, and nothing if both lines were there. An existing `.gitignore` now gains missing lines in the audit
  log too (it used to be left alone; two `AuditLogTests` expectations were updated).
- **Server version from a new reader call** (`ServerVersionAsync`, one more unpooled connection per script), not
  folded into the inventory and not written by SMO.
- **SMO rewrites every DML trigger's `CREATE TRIGGER … AS` header** (bracketed, schema-qualified) whatever
  `TextMode` or `SchemaQualify` is; only the body is kept (probed directly). Emmz chose to **normalise in the test**:
  the round trip drops a DML trigger's header up to its `AS`, and blanks system-generated constraint names on table
  types (SQL Server can't name a table type's constraints, so they always differ). Both are in the README.
- **An empty `objects` list is refused** ("objects is empty. Name at least one object, or leave objects out…"), not
  read as the whole database.
- **If the audit write fails and the script can't be deleted either**, the path goes to the server's stderr
  (`session.Diagnostics`) so a person can remove it; the agent still gets only audit-unavailable.
- **Known gap, accepted:** for chosen objects, the inventory is narrowed to the chosen names, so an encrypted DML
  trigger on a chosen table is left out without being listed. Noted in the README.

Other decisions:
- A failed step's duration is measured from the start of the call, not the step's own.
- IO failures writing the file are `FailureKind.Other` ("Couldn't write the script file: …"); a generator failure
  or cancellation leaves no file (temp deleted in `finally`); the generator rethrows `OperationCanceledException`.
- Header values have control characters replaced, so an identifier can't break out of its comment line.
- `Counts` is keyed by wire type name, sorted; `IReadOnlyDictionary<string, int>` was added to the audit shape
  test's allowed types.
