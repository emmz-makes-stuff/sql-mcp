Emmz's answers before the commit:
- **She approved every choice I had made myself:**
  - `db add` without `init` creates `.sql-mcp/`, `.gitignore` included;
  - `db add` refuses an unparseable connection string, and adds an identity-unavailable one with a warning;
  - `allow` or `deny` that changes nothing doesn't write the file, so no approval lapses;
  - a JSONC removal also removes a comment on the same line;
  - `approve` checks for a terminal first, trims the typed name and compares it case-sensitively, and shows its
    diff as `allows ddl, maxRows 1000 → 5000`;
  - Codex `--force` also removes sub-tables;
  - OpenCode prefers an existing `.jsonc` and refuses a major version other than 1 or 2;
  - the README advises single quotes.
- **`db add` refuses a literal password for the project config.** A side agent raised it; I had considered a
  warning and dropped it without asking. Any `Password`/`PWD` value that isn't a whole `${env:NAME}` reference is
  refused, with `DbCommand.LiteralPasswordMessage`, and there's no override. `--user` is unaffected.
  `ConnectionStringMasker.HasLiteralSecret` shares its key logic with `MaskRaw`. An empty password isn't counted.
- **The Windows `.cmd` shim lookup is fixed now, untested on Windows.** `ProgramLookup.Resolve` walks PATH and
  PATHEXT on Windows only, and is unit-tested for the lookup. Windows starts a `.cmd` file through cmd.exe, which
  parses the arguments its own way. Our arguments are names, paths and a package id.

What landed:
- **Cli plumbing:**
  - `CliContext` holds the directories, `GetVariable`, an `ITerminal` and an `IProcessRunner`, plus `Paths()`.
  - `CliAction.Set` turns a `CliException`, `ConfigException`, `IOException` or `UnauthorizedAccessException` into
    its message on stderr and exit 1.
  - `SqlMcpCli.Build` builds the root, and `Program.cs` is one line.
- **`init`:** `InitCommand.ConfigContent` is also the starting text for any missing config file.
  `ProjectLayout.EnsureGitIgnore` is shared with `AuditLog`. The schema has a `$id` equal to
  `ProjectLayout.SchemaUrl`.
- **`Configuration/JsoncEditor`:** `Get`, `Exists`, `Set` (creates missing objects), `Append` and `Remove`, keyed by
  `JsoncSegment` (implicit from string or int).
  - It follows the document's indent unit and CRLF, keeps inline arrays inline, and maps UTF-8 byte offsets to char
    offsets.
  - Every edit re-parses the result.
- **`AtomicFile`:** writes a temp file beside the target and renames it into place.
- **`ConfigFileEditor.Apply`:** splices the edit, then runs `ConfigLoader.Parse(path, text, _ => null)` (schema plus
  duplicate identities), then writes atomically.
- **`ConfigTarget`:** picks the project or user file, does `IndexOf(id)` with its hint, and runs `Edit(edit, done,
  result)`, which prints `done` and then the approval warning.
- **Commands:** `DbCommand`, `GrantCommands`, `ConfigShowCommand` and `ApproveCommand`, the last with
  `NotInteractiveMessage` and no options.
- **`Cli/Registration/`:**
  - `RegisterCommand` takes `--scope` (default user), `--launcher` and `--force`. On failure it prints the
    client's error, then "To register by hand, add this to <file>:" and the snippet.
  - `LaunchCommand` checks PATH for `sql-mcp`, otherwise uses `dnx Emmz.SqlMcp@<version without +sha> serve`.
  - The strategies are Claude, Gemini, Codex (Tomlyn syntax tree for project scope) and OpenCode (JSONC editor;
    v1 `mcp.sql-mcp` with `enabled`, v2 `mcp.servers.sql-mcp`).
  - Tomlyn is now referenced by `SqlMcp.csproj`. It was already pinned, and its first restore ran unsandboxed.
- **README:** install, quick start, the command table, a full config example, the layering and approval rules, and
  the audit log.

Gotchas:
- **Double quotes break the connection string at a shell.** bash, zsh and PowerShell all expand `"${env:APP_PW}"`
  themselves, which is why the docs and CLI hints use single quotes.
- **`DbConnectionStringBuilder` lower-cases keys**, so `config show` prints `password=***`. It's cosmetic, and left
  as it is.
- **Tomlyn needs a leading newline trivia on the new table's `OpenBracket`:** one line break if the file ends with
  one, two if not.
- **`gemini mcp list` and `claude mcp get` health-check servers**, so detection can be slow.
