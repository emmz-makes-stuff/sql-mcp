The stop and its fix:
- With `global-json-file`, setup-dotnet installs by channel through
  `aka.ms/dotnet/10.0.4xx/…`. That link redirects to `dotnetorigin.blob.core.windows.net`, which answers **409
  `PublicAccessNotPermitted`** (Azure's response to an anonymous read of a storage account that doesn't allow
  public access) for every version.
- An exact `dotnet-version` makes the install script use the feed hosts (`builds.dotnet.microsoft.com`), which work.
- **The pin needs bumping by hand** with each 10.0.4xx SDK, and must stay inside `global.json`'s band. A comment in
  `ci.yml` says why. If the aka.ms redirect is fixed later, switching back to `global-json-file` is an option.
