# §5 Audit log done

<!-- Section: 5 · Tasks: 5.1–5.2 · Base: f5456ba -->

The event shape and Emmz's "no message in `failed`" answer are in `20261025-1806-decision-audit-shape.md`.

What landed (in `src/SqlMcp/Audit/`):
- **`AuditEvents.cs`:** six typed records (`SessionStartEvent`, `SessionEndEvent`, `ExecutedEvent`,
  `DeniedEvent`, `FailedEvent`, `IntrospectionEvent`), plus `FailureKind`.
- **`AuditLog.Open(projectDir, fallbackDir, TimeProvider, pid)`:**
  - **Where it writes:** `.sql-mcp/logs/` if `.sql-mcp/` exists and is writable, creating `.gitignore` if it's
    missing. Otherwise the fallback (`AuditLog.FallbackDirectoryForCurrentUser()`). Otherwise it is unavailable,
    with `UnavailableReason` for stderr.
  - **API:** `Write(event)` → bool, `WriteSessionStart(version, configFiles)` (fills in `log_path` and `pid`),
    `IsAvailable`, `AuditLog.UnavailableMessage` (the agent-facing "audit log unavailable" text) and
    `Serialise` (internal, used by the tests).
  - **Failure handling:** a write failure, or `Dispose`, makes the log unavailable for good.
- **Tests:**
  - `AuditLogTests` covers each audit-log scenario plus concurrency. It changes directory permissions, so the
    class is `[UnsupportedOSPlatform("windows")]`.
  - `AuditEventShapeTests` is a reflection guard: only listed field names and simple types are allowed, so a new
    field needs a deliberate decision.
  - `AuditGitIgnoreTests` runs real `git init` and `git status --porcelain`.
- **`tests/SqlMcp.Tests/FakeTime.cs`:** a manual `TimeProvider`. §6 eviction will need timer support; extend it
  then, or override `CreateTimer`.

For §7 to wire:
- write session start and end;
- check `IsAvailable` first on every call, and return `AuditLog.UnavailableMessage`;
- audit each outcome.

The server version for `session_start` comes from the assembly's informational version.
