Both findings came from the §10 E2E run (`20261025-2021-section-10-done.md`).

Emmz's answers before the code:
- **11.2 design: the caller passes the set.** `ClassificationResult.ForTool(tool, withTools)` takes the categories
  that have a tool. `ToolCatalog.Categories` (just `Query`) lives next to the tool list, and `ToolPipeline` passes
  it. The classification layer still knows nothing about the server. **write-tools extends `Categories`** when it
  adds the command, ddl and execute tools.
- **The batch wording follows the same pattern:** "statement 2 (line 1) classified as ddl; this server has no ddl
  tool yet. The whole batch is rejected, so nothing in it runs."

What landed:
- **11.1:** `internal abstract record AuditEvent([property: JsonIgnore] string EventType)`. Each subtype passes its
  type through the base constructor (`: AuditEvent("executed")`).
  - Why: System.Text.Json didn't apply `[JsonIgnore]` on the abstract property to the overrides, so every line had
    `"event_type"` as well as `"event"`.
  - The new test `Serialised_events_carry_their_type_once_as_event` checks that `OneOfEach()` covers all six
    subtypes, that `event` equals `EventType`, and that there's no `event_type`.
  - **It fails on the old `AuditEvents.cs`** ("SessionStartEvent also has event_type"), checked with `git stash`.
  - The older shape test missed it because it skips `EventType` by name, and nothing asserted on the serialised
    key.
- **11.2:** `Describe(statement, withTools)` gives "classified as X; use the X tool" when X has a tool, and
  "classified as X; this server has no X tool yet" when not.
  - **Spec:** the requirement text now covers both. The "Wrong tool" scenario gains "and the server has a command
    tool", and there's a new scenario, "No tool for that category yet".
  - **Docs:** `docs/classifier.md` step 4 says the same.
  - **Tests:** `ClassifierTests` pass `AllTools` to the existing calls, and add single and batch tests with
    `QueryOnly`. `ToolPipelineTests` and `ServeTests` expect the new text end to end.
- The old reason string is left as arbitrary sample data in a few `AuditLogTests`/`AuditEventShapeTests` events.
